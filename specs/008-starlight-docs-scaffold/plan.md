## Summary

Add a self-contained Astro Starlight project in `docs/` with English (default) and German locales, a five-group autogenerated sidebar, 19 placeholder pages per locale, a CI workflow that builds the docs (no deploy), and a "Documentation" section in `CLAUDE.md`. No PHP code changes. `.gitattributes` already contains `/docs export-ignore` (issue #1), so the distribution archive stays clean.
